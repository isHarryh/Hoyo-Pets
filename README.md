## 介 绍 <sub>Intro</sub>

### 背景

HoyoPets 是基于 [ArkPets](https://github.com/isHarryh/Ark-Pets)（明日方舟桌宠）项目的二次开发。后者是 2022 年创立的桌宠项目，历经数年开发，功能已经非常完整。而 HoyoPets 继承了 ArkPets 的几乎全部特性！

### 实现的功能

1. **支持将《崩坏·星穹铁道》二周年网页活动中出现的角色模型作为桌宠启动。**
2. **启动器提供图形用户界面以便浏览模型和调整各种设置。**
3. **支持 ArkPets 中的几乎全部特性。**

### 快速上手

1. 请[**前往此页面**](https://github.com/isHarryh/Hoyo-Pets/releases)下载最新的 **HoyoPets-Setup.exe** 安装包。
2. 运行安装包并进行软件的安装。安装完成后，打开 HoyoPets 启动器。
3. 首次使用时**无需**下载[模型文件](https://github.com/isHarryh/Hoyo-Spine-Models)，已随安装包附带了《崩坏·星穹铁道》二周年网页活动的小人模型。
4. 在启动器 “模型” 页面中检索并选中想要作为桌宠启动的角色，最后点击左下角 “启动” 按钮即可生成桌宠。

### 其他特性

HoyoPets 完美地继承了 [ArkPets](https://github.com/isHarryh/Ark-Pets) 项目的几乎所有特性！详细内容请参阅 ArkPets 项目的[介绍文档](https://github.com/isHarryh/Ark-Pets?tab=readme-ov-file)。

### 高级用法

在[快速上手](#快速上手)中介绍的是最简单和普遍的使用方法。除此之外：

- 您还可以下载 `zip` 版的程序压缩包解压，实现免安装使用。
- 如果您的电脑上存在 `JDK17` 的 [Java](https://www.java.com) 运行环境，您还可以下载 `jar` 版的程序文件直接运行（但无法使用开机自启动功能，且需要自行前往下载并解压[模型文件](https://github.com/isHarryh/Hoyo-Spine-Models)）。
- 如果您想用命令行启动桌宠，[点击查看](docs/CmdLine.md)说明。
- 如果您想使用直播流软件捕捉桌宠窗口，可以在启动器 “选项” 页面禁用 “桌宠作为后台程序启动”。

目前本程序不支持在其他操作系统运行。好消息是，对于 MacOS 和 Linux 的支持已处于开发阶段，敬请期待。
